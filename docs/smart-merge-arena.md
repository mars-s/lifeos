# Smart merge arena synthesis

October 1, 2026. Design-only arena, all Sol medium following the user's existing preference. Two independent candidates completed. A third dispatch and fallback attempt failed due to the agent thread limit, so the arena proceeded with N-1. A separate read-only Sol medium cross-judge ran after both completed. Same-model diversity is reduced.

Both candidates converged on authentic retained bases, per-field three-way comparison, whole-string titles and cloud preference as fallback. The parent read all designs and rationales end to end. Parent scores: candidate 1 18/25, candidate 2 21/25. Cross-judge: 16/25 and 18/25. Both selected candidate 2 for the smaller evidence model and safer interrupted-write rule.

Base: candidate 2. Grafts: candidate 1's separate append-only post-write divergence disposition, retained alternatives, and a supported semantic field vector for Trash. The final design narrows that disposition to review with exact receipt/capture proof, not an unsupported claim of newer user intent. It excludes derived list/index/time metadata from conflict detection.

Verification found a shared defect: desired equal to base does not mean no intent for an explicit setter. The synthesis introduces explicit_set versus derived_patch. Verification also found candidate 1's before-value replay can erase a post-application edit that returned to the old value; version 3 uses verification-only ambiguous recovery.

Rejected: LLM inference for every sync, title word splicing, wall-clock winner selection, a full CRDT task database, fabricated bases, replay after ambiguous side effects, private database writes, permanent deletion, and new unsupported fields. Rich per-transition history remains deferred unless concrete basis/audit requirements need it.

Verification result: current code inspected; scenario traces reviewed for stale bases, explicit reaffirmation, observed-before return after crash, overlay ownership and stale snapshots. This is a reviewed implementation specification, not executed production tests. No live task operations, deployments or app changes occurred in this arena. The deployed behavior remains version 2 cloud_wins.
