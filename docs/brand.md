# LifeOS brand guide

LifeOS uses warm ivory, charcoal and acid green. The orbit motif represents the connections between thoughts, tasks and time.

This identity currently applies to repository artwork and documentation. It does not change the existing ChatGPT card styles or native app icon.

## Colours

| Name | Hex | Use |
| --- | --- | --- |
| Paper | `#F3F1E8` | Backgrounds. |
| Ink | `#20231F` | Text, wordmarks and primary shapes. |
| Signal | `#C4E86B` | Highlights and active elements, with Ink text. |
| Mist | `#E5E8DD` | Secondary panels. |
| Slate | `#505A45` | Secondary text on Paper. |

Use Signal for accents, not small text on Paper. Keep text readable without relying on colour alone.

## Typography and copy

Use a system sans-serif stack for interfaces and diagrams. The wordmark is written `LifeOS`, with no space. Set headings in sentence case.

The project tagline is "Less to remember. More room to think."

Describe specific actions and limits. Do not imply that every tool works offline, every call is free, or raw text never leaves the machine.

## Artwork generation

The hero was generated with the built-in image-generation tool on 5 October 2026. The final prompt was:

```text
Use case: ads-marketing.
Asset type: wide GitHub README hero banner for the open-source project LifeOS. Generate a polished original brand identity, not a screenshot.
Primary request: An editorial, sophisticated macOS-inspired brand composition. Warm ivory paper background #F3F1E8, almost-black charcoal #20231F typography, restrained acid green #C4E86B accents. Wide landscape around 2.5:1, generous margins, beautifully balanced Swiss design.
Text verbatim: "LifeOS" as a very large impeccably typeset wordmark on the left, sans-serif neo-grotesk, medium weight, crisp kerning. Beneath it a smaller readable line "Less to remember. More room to think." At top left, tiny uppercase "LOCAL-FIRST / AGENT-DRIVEN". No other text.
Subject on right: a striking sculptural orbital emblem, three overlapping continuous charcoal elliptical ribbons with one acid-green ribbon, appearing as a precise abstract organisational system, soft subtle depth and contact shadows, not a planet or atom clipart. Tiny subtle connected green and charcoal nodes around the orbit suggest linked tasks, calendar and remembered thoughts. Extremely refined, quiet, original, no busy dashboard.
Composition: typography left 55%, orbital sculpture right 45%; clean flat ivory background with barely perceptible paper texture; readability at GitHub's 850px width.
Constraints: no real app logos, no watermarks, no fake interface screenshot, no people, no gradients or purple glow, no borders or card stacks. Do not add any text beyond the exact three strings.
```
